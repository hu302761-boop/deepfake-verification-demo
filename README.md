# Deepfake Video Explainable Verification Demo

硕士毕业论文配套的交互式研究型产品原型。项目把深度伪造识别研究转译成普通用户可以理解的“线索、限制、下一步核验路径”，而不是输出无法解释的真假分数。

## 展示内容

- 物理层：边缘、噪声和面部关键点等候选线索
- 多模态层：音频变化和音画同步等候选线索
- 逻辑层：人物、事件、来源和时间线的交叉核验
- 可解释诊断：根据用户勾选的观察线索生成复核建议

## 运行说明

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-demo.txt
python deepfake_demo_app.py
```

完整运行需要本地研究结果目录中的确定性计算摘要和图表。本公开仓库不包含原始视频、受试者数据、论文材料或个人实验文件；这些材料留在本地研究目录中。

## 项目角色

胡静负责研究问题拆解、三层分析框架、交互原型需求、解释边界和 AI 辅助实现迭代。项目仍是研究型原型，不宣称具备任意视频的自动检测准确率，也未对外部署。
